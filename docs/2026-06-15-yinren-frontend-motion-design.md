# 印人传知识图谱智能体前端动效改造设计

日期：2026-06-15

## 设计读取

这是一个用于课堂展示与本地交互的《印人传》知识图谱智能体前端。目标不是做商业官网，也不是做通用后台，而是做一个兼具文学气质、学术展示感和图谱表达力的本地知识图谱产品界面。

视觉语言采用混合型方案：

- 页面层：文献卷轴气质
- 图谱层：关系网络与图结构分析的流动动画
- 交互层：统一使用 Lucide 图标，提升专业感与一致性

## 约束

- 保持当前 Flask + Jinja + 原生 HTML/CSS/JS 结构
- 不引入 React、前端框架或与课程无关的重型技术
- 不影响当前问答、SPARQL、关系网络、图结构分析的既有功能接口
- 动画必须支持 `prefers-reduced-motion`

## 目标效果

### 1. 开屏像册页展开

开屏不只是淡入淡出，而是更接近册页展开、印谱启封的感觉。

实现目标：

- 现有 opening screen 保留，但改成双层展开结构
- 中央标题区先轻微缩放与上浮
- 左右两侧加入“纸页拉开”或“卷轴揭启”遮罩
- 背景印章和墨线缓慢显现，再退入主界面

用户感知：

- 第一眼就能感到与“印人传”有关
- 不像常见科技产品 splash screen

### 2. 页面切换像翻卷 / 揭页

顶部导航切换不能只是 `display: none/block` 的硬切换，需要带有轻叙事感的过场。

实现目标：

- `tab-panel` 切换时增加：
  - 旧面板轻微左移和透明退场
  - 新面板从右侧或下方揭入
  - 面板头部、主体卡片、表格区域分层 stagger 浮现
- 整体节奏控制在 280ms 到 520ms
- 不做真实 3D 翻书，避免过重和廉价感

用户感知：

- 像翻阅文献章节
- 每个模块进入时有“新页展开”的感觉

### 3. 分析卡片像题签浮现

图结构分析四块需要从静态卡片升级为更适合答辩展示的“分析题签”。

覆盖模块：

- 中心性分析
- 社区发现
- 路径分析
- 流派演变分析

实现目标：

- 卡片进入时分批浮现
- 卡片顶部或左侧加入题签式强调条
- 卡片背景加入轻微光扫或墨迹扩散感
- 鼠标悬停时卡片轻微上浮
- 点击后保持与关系网络联动高亮

用户感知：

- 每一块分析都像展签或学术图录中的注记条目
- 更有“附加项已经认真完成”的展示感

### 4. 关系网络更强的动态图谱感

关系网络是答辩里最容易形成记忆点的部分，需要明显强化。

实现目标：

- 节点呼吸：
  - 所有节点低频脉冲缩放
  - 中心节点呼吸更明显
- 边流动：
  - 使用虚线偏移或渐变高光模拟关系流动
  - 师承、交游、流派、亲属四类边颜色和动画节奏区分
- 路径追光：
  - 路径分析结果高亮时，路径边加入流动追光
- 社区涟漪：
  - 点击社区结果时，相关节点增加柔和外圈扩散
- 查询联动高亮：
  - 智能问答 / SPARQL 的结果命中人物在全量图谱中高亮

用户感知：

- 不是静态 SVG 点线图
- 更像“活的知识关系图”

### 5. 图结构分析与网络图联动

分析面板和关系网络不能是两张独立页面，它们应该相互照亮。

实现目标：

- 点击中心性人物：
  - 自动切换或滚动到关系网络区域
  - 以该人物为中心高亮
- 点击社区发现结果：
  - 关系图中对应社区人物整体提亮
  - 其他节点适度降噪
- 点击路径分析结果：
  - 关系图沿路径逐步亮起
- 点击流派演变结果：
  - 高亮流派及其创始人、代表人物和相关节点

用户感知：

- 分析结果不是“读完就结束”
- 会直接回流到图谱可视化中

## 图标系统

全站统一切换为 Lucide 图标。

适用范围：

- 顶部导航
- 状态 badge
- 按钮
- 分析卡片
- 网络图说明区
- 高级查询区域

原则：

- 统一线性风格
- 不混用其他图标库
- 图标只增强结构，不抢标题

## 推荐实现方式

### 方案 A：纯 CSS + 原生 JS

优点：

- 最符合当前工程结构
- 成本低
- 不引入额外依赖

缺点：

- 某些动态图谱效果要手写 SVG 动画和类名切换

### 方案 B：纯 CSS + 原生 JS + 少量 SVG 动画增强

优点：

- 适合当前项目
- 足够实现路径追光、边流动、节点呼吸、社区涟漪
- 风险可控

缺点：

- 动画状态管理会比纯静态页面复杂一些

推荐：方案 B

原因：

- 不改主技术栈
- 可以把“印人传”的文学气质和图谱动感真正做出来
- 对答辩展示最有帮助

## 改造范围

### 会改

- `templates/index.html`
- `static/styles.css`
- 页面内原生 JS 动画和切换逻辑

### 不会改

- Flask 路由设计
- RDF/Turtle/SPARQL 主链路
- LangGraph / LLM 后端逻辑
- 数据抽取与知识图谱建模代码

## 验收标准

完成后应满足以下可见效果：

- 开屏具有册页展开感
- 标签页切换具有翻卷/揭页感
- 图结构分析四块像题签浮现
- 关系网络节点呼吸明显
- 关系边有流动感
- 路径高亮时有追光
- 社区结果点击后出现群体涟漪感
- 页面图标统一为 Lucide
- 手机和桌面端都不崩
- `prefers-reduced-motion` 下能安全降级

## 实施顺序

1. 统一 Lucide 图标与导航结构
2. 改造开屏与标签页切换动画
3. 改造分析卡片视觉和进入动效
4. 改造关系网络节点 / 边 / 高亮动画
5. 完成分析面板与网络图联动
6. 本地验证与展示微调
