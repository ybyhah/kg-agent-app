## 三、实体类型定义

共定义**8种实体类型**，覆盖《印人传》中的核心概念：

### 3.1 人物（Person）
- **定义**: 印人传中出现的篆刻家、文人、官员等相关人物
- **包含角色**: 篆刻家、书法家、画家、文人、官员、学者等
- **示例**: 周亮工、文彭、何震、许友、梁千秋
- **属性**: 姓名、字、号、籍贯、朝代、生年、卒年、身份

### 3.2 地名（Place）
- **定义**: 人物籍贯、活动地、任职地等地理位置
- **子类型**: 
  - 籍贯地（出生地/祖籍）
  - 居住地（移家/定居地）
  - 任职地（官职所在地）
  - 游历地（短暂停留地）
- **示例**: 河南祥符、白下、金陵、休宁、婺源、潍县

### 3.3 时间（Time）
- **定义**: 朝代、年份、生卒年等时间信息
- **时间粒度**: 
  - 朝代（明、清）
  - 年号年份（明崇祯十三年、康熙十一年）
  - 干支纪年（万历四十年壬子）
  - 生卒时间

### 3.4 字号（CourtesyName）
- **定义**: 人物的字、号、别号等
- **子类型**: 
  - 字（表字）
  - 号（自号）
  - 别号（其他称号）
  - 室名（书斋名）
- **示例**: 元亮（周亮工字）、栎园（周亮工号）、减斋（周亮工别号）

### 3.5 书体印风（CalligraphyStyle）
- **定义**: 篆刻风格、书体类型
- **包含内容**: 
  - 篆刻流派风格（汉印法、文何旧习）
  - 书法字体（篆书、隶书等）
  - 技法特点（六书、刀法等）
- **示例**: 汉印法、文何旧习、六书、秦篆

### 3.6 流派（School）
- **定义**: 篆刻流派、师承体系
- **属性**: 
  - 流派名称
  - 创始人
  - 特点描述
- **示例**: 文何派（文彭、何震开创）、皖派

### 3.7 印章（Seal）
- **定义**: 具体的印章名称或印文内容
- **属性**: 
  - 印文内容
  - 材质（玉石、铜、牙章等）
  - 印主（印章拥有者）
- **示例**: "掌风化之官"、"东林书院"、"努力加餐"

### 3.8 作品（Work）
- **定义**: 印谱、诗文集等相关著作
- **子类型**: 
  - 印谱（印章作品集）
  - 诗文集
  - 学术著作
- **示例**: 《印人传》、《读画录》、《印薮》

## 四、关系类型定义

共定义**14种关系类型**，覆盖人物间的各类关联：

### 4.1 亲属关系

#### 父子（Family:Father-Son）
- **定义**: 父亲与儿子的亲属关系
- **方向**: 父亲 → 儿子
- **示例**: 周亮工与周靖公的兄弟关系（可扩展为亲属关系）

### 4.2 师承关系

#### 师承（Master-Student）
- **定义**: 师徒关系，包括正式拜师和私淑学习
- **方向**: 徒弟 → 师父
- **示例**: 
  - 何震师承文彭
  - 文及先师承金光先
  - 金光先师承何震（文何派传承链）

### 4.3 社交关系

#### 交游（Friendship）
- **定义**: 朋友、同好、交往关系
- **特点**: 双向关系，无明确师徒或亲属关系
- **示例**: 
  - 周亮工与许友交游
  - 程穆倩与周亮工交游

### 4.4 流派关系

#### 流派归属（SchoolAffiliation）
- **定义**: 人物属于某个篆刻流派
- **方向**: 人物 → 流派
- **示例**: 何震 → 文何派

#### 开创（SchoolFounding）
- **定义**: 开创某流派或风格
- **方向**: 创始人 → 流派
- **示例**: 文彭 → 文何派

### 4.5 属性关系

#### 字号对应（HasCourtesyName）
- **定义**: 人物与其字号的关系
- **方向**: 人物 → 字号
- **特点**: 一个人物可有多个字号
- **示例**: 
  - 周亮工 → 元亮（字）
  - 周亮工 → 栎园（号）
  - 周亮工 → 减斋（别号）

#### 籍贯（BirthPlace）
- **定义**: 人物的籍贯地
- **方向**: 人物 → 地名
- **示例**: 
  - 周亮工 → 河南祥符
  - 何震 → 婺源

#### 活动于（ActiveIn）
- **定义**: 人物活动或居住的地方
- **方向**: 人物 → 地名
- **示例**: 
  - 周亮工 → 白下（移家）
  - 何震 → 金陵（往来）

#### 任职于（OfficeIn）
- **定义**: 人物任职的地方
- **方向**: 人物 → 地名
- **示例**: 
  - 周亮工 → 潍县（县令）
  - 周亮工 → 两淮（盐运使）

#### 生于（BornIn）
- **定义**: 人物出生时间
- **方向**: 人物 → 时间
- **示例**: 周亮工 → 万历四十年

#### 卒于（DiedIn）
- **定义**: 人物去世时间
- **方向**: 人物 → 时间
- **示例**: 周亮工 → 康熙十一年

#### 擅长（SkilledIn）
- **定义**: 人物擅长的篆刻风格
- **方向**: 人物 → 书体印风
- **示例**: 何震 → 六书篆刻

#### 创作（Created）
- **定义**: 人物创作的印章
- **方向**: 人物 → 印章
- **示例**: 文彭 → [具体印章]

#### 著有（Authored）
- **定义**: 人物撰写的著作
- **方向**: 人物 → 作品
- **示例**: 
  - 周亮工 → 《印人传》
  - 周亮工 → 《读画录》

## 五、输出格式规范

### 5.1 实体JSON格式

```json
{
  "entities": [
    {
      "id": "实体唯一标识符（如：e1, e2...）",
      "type": "实体类型（如：人物、地名...）",
      "name": "实体名称",
      "attributes": {
        "属性名": "属性值"
      },
      "context": "原文出处（用于溯源）",
      "confidence": 0.95
    }
  ]
}
```

### 5.2 关系JSON格式

```json
{
  "relations": [
    {
      "id": "关系唯一标识符（如：r1, r2...）",
      "type": "关系类型（如：师承、交游...）",
      "source": "头实体ID",
      "target": "尾实体ID",
      "context": "原文出处（用于溯源）",
      "confidence": 0.95
    }
  ]
}
```

### 5.3 完整输出示例

```json
{
  "entities": [
    {
      "id": "e1",
      "type": "人物",
      "name": "周亮工",
      "attributes": {
        "字": "元亮",
        "号": "栎园、减斋",
        "籍贯": "河南祥符"
      },
      "context": "君讳亮工，字元亮，号栎园，又号减斋，河南祥符人",
      "confidence": 1.0
    },
    {
      "id": "e2",
      "type": "地名",
      "name": "河南祥符",
      "attributes": {},
      "context": "河南祥符人",
      "confidence": 1.0
    }
  ],
  "relations": [
    {
      "id": "r1",
      "type": "籍贯",
      "source": "e1",
      "target": "e2",
      "context": "河南祥符人",
      "confidence": 1.0
    }
  ]
}
```

## 六、Schema使用说明

### 6.1 抽取流程
1. **NER实体抽取**: 识别文本中的8类实体
2. **属性抽取**: 为人物实体抽取字、号、籍贯等属性
3. **关系抽取**: 基于实体识别14类关系
4. **结果输出**: 按JSON格式输出entities和relations

### 6.2 与后续模块对接
- **成员C（图谱构建）**: 将JSON转换为RDF/Turtle格式
- **成员D（查询问答）**: 基于entities和relations构建SPARQL查询
- **CBDB/CTEXT对齐**: 使用"人物"实体的属性进行外部对齐

### 6.3 质量控制
- **置信度标注**: 每个实体和关系都有confidence字段
- **原文溯源**: context字段保留原文出处，便于人工校验
- **ID唯一性**: 确保实体ID和关系ID全局唯一
